# 记账

给大学生用的每日记账本。打开就能记一笔，数据留在自己手机里，不登录、不上传。

## 怎么用

- 打开就是记账页：点金额、点一个分类，需要的话写备注，然后按「记一笔」。支出可以在「必要」和「想要」之间点一下切换，默认是必要。
- 「明细」里按月查看，点一条可以改或删除。标着「自动」的是固定支出生成的。
- 「我的」里可以改分类和颜色、设每月固定支出（话费、会员）、设一个攒钱目标、设每月预算。
- 已攒 = 从目标开始那天起的收入减去支出。到 25%、50%、100% 会各庆祝一次。
- 预算用到 80% 和用完时，首页会变色提醒。
- 连续记账天数显示在首页。今天还没记，会轻轻提一句。
- 新月份第一次打开，如果上个月有账，会弹出上个月小结。
- 「统计」按月看：分类环形图、全年堆叠柱、收入流向支出的桑基图。没有周报。
- 统计页或「我的」可以打开「示例数据」，用一份虚构账本看图，不会改你的记录。默认关闭。

数据只在这台手机的浏览器里。清除浏览器数据、换浏览器或换手机，账会丢。请在「我的」里经常导出 JSON；换机时再导入。

## 装到主屏幕

用手机浏览器打开一次（要联网）。之后可以离线记账。

- 安卓 Chrome：菜单 →「安装应用」或「添加到主屏幕」。装好后长按图标，点「记一笔」会直接进入记账。也可以打开 `?add=1`。
- iPhone：请用 Safari，分享 →「添加到主屏幕」。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:47321 。

```bash
npm test
npm run build
npm run preview
```

`npm run build` 会在 `dist/` 生成纯静态文件。

## 部署到 GitHub Pages

资源使用相对路径，放在用户站点根目录或项目子路径都可以。

1. 把代码推到 GitHub 仓库的 `main` 分支。
2. 打开仓库 Settings → Pages → Build and deployment，Source 选 GitHub Actions。
3. 仓库里的 `.github/workflows/pages.yml` 会在推送后构建 `dist/` 并发布。

也可以在本机构建后，把 `dist/` 目录里的文件上传到任意静态网站。
